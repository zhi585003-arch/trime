# 布局实时预览与拼音编辑栏

应用版本 3.3.9-offline.7，覆盖现有二版安装；不要卸载或清除数据。

- 离线定制设置 → 布局与实时预览：同一页面调整键盘高度、宽度、左右位置、底部留白、按键字号，以及候选栏高度、放大后的拼音栏高度和字号。下方按当前主题的按键布局实时绘制预览。拖动不会立即保存；保存统一生效，取消保留原值。恢复默认也需保存。
- 默认候选栏加高至 56 dp；可在 40–96 dp 间调整。
- 拼音栏现在位于键盘内部，宽度覆盖整行，不再使用浮动触摸窗口。点拼音放大，再点字母位置移动光标；右侧 ‹ / › 每次移动一位。较长拼音可以横向滚动，光标移动时自动保持可见。输入结束后自动收起。
- 展开后可连续确定音节分界。例如输入 xian，先选 xi，左侧立即显示剩余的 a / an（按有效音节列表），不必先选汉字。显式分界以单引号保存在原始输入里，再选择对应整词或汉字。分界选完会提示选字；可重选音节。已有分界不会重复插入。
- 候选展开页复用，音节表后台读取，跳过展开/收起过渡动画；下箭头不再同时识别下滑隐藏键盘。实际流畅度需要手机确认。
- 振动、长按、签名、包名和离线要求保持现有配置。

手机验收：保存布局后收起再打开键盘，检查三处尺寸；长拼音点开编辑栏，测试两端箭头、直接点字母、横向滚动；xian 依次选 xi、an 后选词；尝试删除分界及继续输入。编译和逻辑测试不能代替真机交互验收。

以下为历史更新记录，旧的“先选汉字再选下一音节”流程已由本版本更新。

# 修复 Rime 软光标导致音节列表为空

应用版本 3.3.9-offline.6，可覆盖现有二版。Rime 会把 U+2038（‸）插入 preedit，例如 xian‸、xi‸an；此前匹配末尾字母的规则因此得到空列表。现在先去除这一非输入标记，再计算原始拼音前缀和光标位置。

新增四项软光标回归测试，覆盖末尾、中间和已选汉字后的剩余音节；结合原有五项，共九项测试。未改振动与长按。

手机验收：输入 xian 展开，左侧应出现 xi / xia / xian；选择 xi、再选择汉字后，检查剩余 an。

# 音节列表修复更新

修复“拼音在输入框内显示”模式下音节列表为空的问题：改从引擎读取真实输入及组合状态，不使用已经清空的键盘显示缓存。选择前缀前验证输入状态，防止旧按钮误作用于新输入。

覆盖安装二版后，输入 xian 展开候选，应显示 xi、xia、xian 等有效前缀。选择 xi 后先选它的汉字，再继续 an。内嵌拼音显示模式不需要关闭。此更新保留已正常的长按选择及振动。

自动测试覆盖前缀和偏移计算；实际引擎候选变化及手机显示仍需验证。

# 二版修复更新

可覆盖安装现有二版，不要卸载或清除数据。修复候选展开读取不存在的颜色导致异常；长按弹窗左右选择不再依赖滑动开关，并允许手指停留在原按键高度。旧主题缺少字母长按配置时使用内置三选一。

安装后先输入 xian 并点候选右侧下箭头，检查候选展开和 xi / xian 等前缀；选 xi 对应汉字后继续选择 an。再长按 h，保持手指不抬起左右移动，检查 H / & / h。若仍关闭键盘，需要导出的崩溃日志确认手机上的实际异常，不能把编译成功当作修复已在真机验证。

# 二版更新：长按选字符与系统触感

本次更新可覆盖安装已经安装的“同文离线雾凇二版”；无需卸载。早期“同文离线雾凇”仍是独立应用。

- 默认同文风的 26 个字母长按后出现“大写 / 上方符号 / 小写”。例如 h 为 H / & / h，默认选中符号；保持按住并左右移动选择，松手输入。边缘按键的弹窗会向屏幕内移动。
- 普通点击仍输入拼音，上划仍输入键帽上方符号。弹窗中选择大小写会直接输入所选拉丁字母。
- 离线定制设置 → 按键反馈 → 振动方式，默认“跟随系统按键触感”。此模式不使用固定 15 毫秒振动，不忽略系统触感开关，不在系统禁止振动时强行补振。
- 可打开“系统声音与振动设置”，以及点击“试一下按键触感”。系统是否开放强度调节、具体触感由手机决定；不能保证与百度的私有适配完全相同。
- 仍可选“自定义时长与强度”，然后调整原有滑块。

验收：长按 h 左右滑动分别选 H、&、h；试 q/p/a/l 边缘键；取消触摸不应输入。系统触感关闭后，系统模式不应继续振动；重新开启后恢复。保持已有个人词库和剪贴板，检查覆盖升级后可正常输入。

# 同文离线雾凇 · 第二版测试说明

安装为独立的“同文离线雾凇二版”，与首版并存。首版的签名缓存未生效，不能覆盖升级；不要卸载或清除首版数据。二版使用明确指定路径的签名缓存。

二版不能直接读取首版私有的剪贴板数据库及设置。已有个人词库请先在首版备份并导出，再在二版恢复。若旧共享用户目录可读取，会复制其中的数据；不依赖这一步保证迁移。

## 新功能

- 剪贴板：点击历史只预览并返回键盘；再点上方文字确认粘贴。只有成功粘贴才置顶、重新计时 24 小时。复制重复内容不续期。收藏仍是单独的长期保存区。
- 默认同文风：字母键上划输入键帽上的数字/符号，k 为 (、l 为 )；退格上划清空当前输入框，普通点击仍是退格。
- 候选栏左右连续滚动，接近末尾继续加载。下拉箭头展开左侧拼音选择与右侧四列候选字；选择前一段对应的汉字后，继续处理剩余拼音。
- 设置主页增加“离线定制：布局、振动与隐私”。高度、宽度、左右位置、底部留白和文字大小独立可调。收起再打开键盘生效，可以恢复默认。
- 按键振动开关、时长及硬件支持时的强度调节。默认 15 毫秒。

## 私有数据及迁移

词库、学习数据、配置及内置资源改用应用私有目录。升级首次启动引擎时，从旧用户目录复制数据并逐文件校验；旧副本保留，复制完成才标记迁移完成。原版输入法不受影响。

确认个人词库正常后，在离线定制设置中选择“删除迁移后留在共享目录的旧副本”。**旧副本未删除前仍可能被有文件权限的应用访问。** 先另存必要备份，再确认删除界面显示的目录。

系统自动备份/设备迁移规则排除本应用数据；文件浏览 provider 已停用。旧版本授予的共享存储权限仅供迁移/清理旧副本，完成后可在系统设置撤回；私有目录正常使用不依赖该权限。

私有数据不是额外加密。Root、受控系统及用户主动导出的文件不在普通应用沙盒保护范围内。输入到其他应用的文字仍会被该应用读取。系统剪贴板与输入法私有历史是不同的数据。

暂停学习使用 native 引擎写入前检查；可以清除学习词库、剪贴板、收藏。清除学习词库不删除你以前主动保存的备份。卸载或清除应用数据会删除私有数据。

## 词库与配置

用户词典页面保留导入、导出、备份和恢复。先在 rime_ice 用户词典中“备份”，再通过离线定制页“导出配置或用户词典备份”把 sync 下的 .userdb.txt 导出到指定位置。恢复用原用户词典页面右下角按钮。

支持导入 .custom.yaml / .trime.yaml，校验语法及主题基本字段，保存旧文件再部署。设置中可以恢复上次配置。语法通过不等于所有高级配置语义都正确，导入自定义主题后仍需验证。普通词条文本请在用户词典页面导入。

## 手机验收（不能用编译成功代替）

1. 确認私有目录迁移后能离线输入简体中文，已有个人词条仍在。
2. 调整高度、宽度、左右位置及底部留白，收起键盘再打开；重启后保持。
3. q 上划为 1，k/l 上划为左右括号。先在空白备忘录验证退格上划清空。
4. 输入较长拼音，候选左右连续滚动；展开后尝试 xian 的 xi、xian，选择前段汉字后查看 an。
5. 点击剪贴板历史不会立即输入；再点上方预览才粘贴并置顶。
6. 关闭学习后输入新词，验证不积累；重新打开后验证正常学习。
7. 备份并导出个人词库，验证恢复入口。

语音输入本轮未加入。APK 仍自动检查不申请 INTERNET 权限。
